# 外链免登访问(share token / 访客管理)

> 一条带令牌的 URL 让**外部人员免登录、只读**查看指定页面。不删不掉登录体系:
> 令牌是「系统设置的**凭证**」,管理入口在「用户管理 ▸ **访客管理**」Tab。

## 一、机制概览

三段接力,每段只负责一小步:

1. **令牌存储**:令牌 / 备注 / 允许页面 / 有效期 / 启停在 **`sys_share_token`** 表里(一行 = 一条外链)。
   存在「启用 ∧ 未过期」的令牌 = 访客开启;**全部停用即关闭** —— 没有额外的总开关,外链一律按未登录处理。
2. **路由守卫**(`routes/(main)/route.tsx` 的 `getSessionGate`,服务端):无会话时读
   URL `?share=<token>`(首跳)或访客 cookie(后续),比对令牌表(含过期检查)。
   命中且页面在令牌的**允许路径**里 → 以「访客」身份放行;URL 令牌先写 httpOnly cookie、
   **307 重定向回摘掉 `share` 参数的同一地址**(同一请求里页面数据还拿不到刚下发的 cookie,
   必须让浏览器带着新 cookie 再来一次,顺带令牌从地址栏消失)。
3. **数据层**(`lib/current-user.ts` 的访客兜底 + `integrations/trpc/init.ts` 的访客特判):
   无会话时读同一颗 cookie 认人;访客以管理员视角读取所有 query 和数据范围,mutation 一律 403。

URL 最终形态:`https://域名/目标页面?share=<令牌>`(首跳之后 307 摘参,地址栏不再带令牌)。

## 二、表 `sys_share_token`(39 张系统表之一)

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | varchar(32) PK | nanoid |
| `token` | varchar(64) 唯一 | 令牌本体,32 位 hex(服务端 `randomBytes(16)` 生成);**明文存** —— 管理页「复制链接」要随时拿得到 |
| `remark` | varchar(255) | 备注(发给谁、看什么) |
| `allowed_paths` | text | **JSON 数组字符串**,路径前缀,如 `["/demo/grid"]`(最多 10 条,校验在 `lib/share-token-spec.ts`) |
| `expires_at` | datetime NULL | 过期时刻(建到当天 23:59:59);null = 长期有效 |
| `enabled` | tinyint | 1 启用 / 0 停用 —— **行级启停就是总开关** |
| `created_at` / `updated_at` | datetime | 时间默认走 `.$defaultFn`(达梦 DDL 默认值差 8 小时,见 doc/达梦支持.md) |

⚠️ **凭证表,硬删**(不加 `deleted_at`,与 `sys_rate_limit` 同档,见 `lib/soft-delete.ts` 的运维表口径):
删除 = 这条外链立即失效,留痕走 `sys_log` 审计。唯一键 `uk_sys_share_token(token)` 因此不需要墓碑。

## 三、代码地图

| 文件 | 职责 |
| --- | --- |
| `lib/share-access.ts` | 判定核心(纯服务端):`matchShareToken`(sha256 + `timingSafeEqual` 常数时间比对 + 过期检查,行清单 30s 缓存)、`guestMayView`(允许路径前缀匹配 + `/settings` 禁入)、cookie 读写、`newShareToken` |
| `lib/share-token-spec.ts` | 客户端可用的规格:允许页面多行文本校验、过期折算(与 `para-spec.ts` 同一条「不许 import `#/db`」界线) |
| `lib/current-user.ts` | 会话为空时的**访客兜底** → 返回 `{ id: "share-guest", name: "访客", sharePaths }`;tRPC 的 `requireUser` 经此认人 |
| `integrations/trpc/init.ts` | `permMiddleware` 访客特判(mutation 一律拒;query 使用管理员读视角);`dataScopeMiddleware` 访客放行(无角色无部门,部门口径只会筛成空) |
| `routes/(main)/route.tsx` | 守卫 share 分支 + 首跳 set-cookie + 307 摘参 |
| `integrations/trpc/routers/share-token.ts` | `sys_share_token` 的 CRUD(`list` / `create` / `update` / `toggle` / `remove`),四个写口都 `clearShareTokenCache()` |
| `components/modules/settings/guests/*.tsx` | 「访客管理」Tab 的台账 / 表单 / 详情 |

## 四、安全边界

- **访客只读**:所有 mutation 一律 `403 外链访客只读,不能执行该操作`(审计照记,见 sys_log 的失败行);
- **页面入口受限,数据读取不受路径约束**:路由守卫只允许打开令牌指定的路径,且 `/settings/*` 禁入。但任何有效访客令牌都能直接调用所有读接口,包括管理数据和其他资源,并绕过行级范围及管理员资源检查。路径不是数据隔离边界,签发前须确认接收者可以读取全部数据;
- 令牌是 httpOnly cookie,前端 JS 摸不到;比对是常数时间;令牌只在首跳 URL 上出现过一次;
- cookie 8 小时过期,重开外链即可(令牌未变就还能进);**停用 / 删除 / 改令牌 → 立即失效**(写口清缓存);
- 高敏感内容请配合 HTTPS + 短 `expires_at`(历史记录 / 引用页仍可能带着首跳 URL)。

## 五、使用

1. 「用户管理 ▸ 访客管理」Tab → 「新增令牌」:填备注、允许页面(路径前缀,每行一条)、有效期(可空 = 长期);
2. 行操作「复制链接」= `origin + 第一个允许页面 + ?share=<token>`,发给外部人员即可;
3. 作废:停用 / 删除该行;延期 / 改范围:「编辑」(令牌本体不变,已发链接继续有效)。

## 六、已知陷阱

- **首跳重定向必须 `redirect({ to, search })`**:`redirect({ href: 相对路径 })` 会被当成外部跳转,实测 500;
- 允许页面是**路径前缀**,目标页面最好是静态路径;带路由参数(`:id`)的页面按整段前缀匹配,想清楚再发;
- 访客查询使用管理员读视角,包括文件、任务和管理数据;写接口仍由中间件统一拒绝。
- **令牌表的建表 DDL 同步在两处**:`scripts/create-system-tables.ts`(MySQL)+
  `scripts/create-better-auth-tables-dm.ts`(达梦),漂移会在运行期报 Model not found,`typecheck` 抓不到。
